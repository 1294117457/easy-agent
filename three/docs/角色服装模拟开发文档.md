# Three.js 角色服装模拟 - 开发文档

> 基于 Three.js 的实时布料模拟与角色交互系统

---

## 项目概述

### 目标

实现一个可交互的角色服装模拟系统：用户通过键盘控制简单人形模型（胶囊体）移动，独立模拟的布料服装跟随身体运动，由于物理特性产生自然延迟和摆动效果。

### 核心技术点

| 模块 | 技术选型 |
|---|---|
| 3D 渲染 | Three.js |
| 物理模拟 | 自实现 Verlet 积分 + 弹簧-质点系统 |
| 角色模型 | 程序化生成的胶囊体（无外部模型依赖） |
| 碰撞检测 | AABB 包围盒 + 顶点-球体距离检测 |
| 构建工具 | Vite |
| 开发语言 | TypeScript |

### 预期效果

- 角色站立时服装自然下垂
- WASD 移动时服装因惯性产生延迟跟随
- 快速转身/急停时服装产生飘动/摆荡效果
- 多块布料（披风/裙摆）可独立模拟

## 物理系统设计

### 1. 粒子 (Particle)

每个布料顶点作为一个粒子：

```typescript
interface Particle {
  position: Vector3;    // 当前坐标
  prevPosition: Vector3; // 上一帧坐标（用于 Verlet 积分）
  acceleration: Vector3; // 受力加速度
  mass: number;          // 质量（通常为1）
  pinned: boolean;        // 是否固定（用于固定到角色身上）
}
```

### 2. 弹簧约束 (Spring)

连接相邻粒子的约束力：

```typescript
interface Spring {
  p1: Particle;
  p2: Particle;
  restLength: number;  // 自然长度
  stiffness: number;   // 刚度系数 (0~1)
}
```

### 3. Verlet 积分

核心物理更新公式：

```
velocity = (position - prevPosition) * damping
prevPosition = position
position = position + velocity + acceleration * dt * dt
```

参数说明：
- `damping`：速度衰减系数（0.97~0.99），模拟空气阻力
- `dt`：时间步长，需固定（如 1/60）
- `acceleration`：重力 + 风力 + 碰撞力

### 4. 约束求解

每帧多次迭代求解弹簧约束（Position-Based Dynamics）：

```typescript
for (let i = 0; i < constraintIterations; i++) {
  for (const spring of springs) {
    const delta = spring.p2.position - spring.p1.position;
    const distance = delta.length();
    const correction = delta * ((distance - spring.restLength) / distance);
    // 非固定点分担修正量
    if (!spring.p1.pinned) spring.p1.position += correction * 0.5;
    if (!spring.p2.pinned) spring.p2.position -= correction * 0.5;
  }
}
```

推荐迭代次数：5~10 次，次数越多越刚性，但性能下降。

## 布料绑定方案

### 方案 A：跟随点（Pinned Points）

布料顶部一排粒子固定在角色肩部/胸部位置，每帧同步世界坐标：

```typescript
// 每帧更新
for (const pinnedParticle of cloth.pinnedParticles) {
  const targetWorldPos = character.getBindPoint(pinnedParticle.bindIndex);
  pinnedParticle.position.copy(targetWorldPos);
}
```

**优点：** 实现简单，物理模拟自然
**缺点：** 布料与身体连接处可能出现穿插

### 方案 B：碰撞驱动（推荐）

- 绑定点用方案 A 同步
- 布料内部粒子与角色胶囊体做碰撞检测
- 检测到穿透时施加排斥力

```typescript
// 碰撞检测
for (const particle of cloth.particles) {
  const closest = capsule.closestPoint(particle.position);
  const distance = particle.position.distanceTo(closest);
  if (distance < cloth.thickness) {
    // 施加排斥力
    const pushDir = particle.position.clone().sub(closest).normalize();
    particle.position.add(pushDir.multiplyScalar(cloth.thickness - distance));
  }
}
```

## 风力系统

使用简化的 Perlin 噪声模拟自然风：

```typescript
class Wind {
  update(time: number): Vector3 {
    const strength = 2.0;
    return new THREE.Vector3(
      Math.sin(time * 0.7) * strength,
      0,
      Math.cos(time * 0.5) * strength * 0.5
    );
  }
}
```

## 性能优化

### 粒子数量控制

| 布料尺寸 | 网格分辨率 | 粒子数 | 性能 |
|---|---|---|---|
| 10x10 | 10x10 | 121 | 极佳 |
| 20x15 | 20x15 | 341 | 良好 |
| 30x20 | 30x20 | 651 | 一般 |

推荐分辨率：**20x15**，性能和效果平衡。

### 固定时间步长

```typescript
const FIXED_DT = 1 / 60;
let accumulator = 0;

function animate(time: number) {
  const dt = (time - lastTime) / 1000;
  lastTime = time;
  accumulator += dt;

  while (accumulator >= FIXED_DT) {
    updatePhysics(FIXED_DT);
    accumulator -= FIXED_DT;
  }
  // 渲染使用 accumulator 插值，避免帧率依赖
}
```
