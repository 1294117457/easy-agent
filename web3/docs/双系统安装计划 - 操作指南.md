## 场景

- 电脑：华硕灵耀14-2024版
- 硬盘：1TB
- 需求：学习开发为主，偶尔使用 Windows 专属软件

------

## 一、电脑发热问题排查（出发前可做）

1. 打开任务管理器，查看哪个进程 CPU/内存占用高
2. 检查启动项：`Win + R` → `msconfig` → 启动
3. 考虑送修检查散热系统

## 三、重装流程

备份数据 → 制作 Windows 安装U盘 → 全盘清除重装 Windows 

→ Windows 分出 200GB → 制作 Linux 安装U盘 → 安装 Linux → 完成

### 详细步骤

#### 1. 制作 Windows 安装U盘

- 下载：微软官网 Media Creation Tool
- 准备 8GB+ U盘

#### 2. 全盘清除 + 重装 Windows

- U盘启动 → 选择"自定义" → 全盘删除 → 安装 Windows
- 联网后 Windows/O365 会自动激活

#### 3. Windows 分区

- 磁盘管理 → 压缩 C盘 → 分出 200GB 给 Windows
- 剩余空间留作未分配（给 Linux）

#### 4. 制作 Linux 安装U盘

- 推荐发行版：Ubuntu LTS 或 Linux Mint
- 下载 ISO → 用 Rufus/Etcher 烧录到U盘

#### 5. 安装 Linux

- U盘启动 → 选择"其他选项"手动分区
- 分区建议：

| 分区   | 大小  | 文件系统 |
| :----- | :---- | :------- |
| / (根) | 750GB | ext4     |

#### 6. 完成

- GRUB 自动配置双引导菜单
- 开机时选择进入哪个系统

## 六、注意事项

- Secure Boot：BIOS 中可能需要禁用或设置为允许第三方 OS
- Office 激活：重装前登录 account.microsoft.com 确认状态
- 恢复U盘：用华硕工具制作 Windows 恢复U盘（以防万一）
