##### 1.核心模块

```
domain
	entity、input port、output port
infra
	input adapter、output adapter
application
	业务逻辑代码
```

##### 2.具体实现

```
外部请求->input adapter->input port->应用
应用实现功能->output port->output adapter
```

```
Input Adapter（输入适配器）                                   │
  ────────────────────────────                                  │
  · 属于 infra 层                                               │
  · 实现 input port                                             │
  · 负责接收外部请求（HTTP、Tauri Command、CLI 等）            │
  · 调用 application 的用例                                     │
                                                                │
Output Adapter（输出适配器）                                  │
  ────────────────────────────                                  │
  · 属于 infra 层                                               │
  · 实现 output port                                            │
  · 负责访问外部资源（DB、文件系统、第三方 API）               │
  · 被 application 调用                  
```

```
内部entity互相直接调用

impl User {
    pub fn total_spent(&self) -> f64 {
        self.orders.iter().map(|o| o.amount).sum()  // ✅ 内部实体互调
    }
}
// ========== 外部调用（需要 Output Port）==========
impl User {
    // 用户想要持久化自己
    pub fn save(&self) {
        // ❌ 错误做法：直接依赖 SQLite
        // let conn = SqliteConnection::connect("db.sqlite");
        // conn.execute("INSERT INTO users...");
        
        // ✅ 正确做法：通过 Port 解耦
        let storage: impl StoragePort = get_storage();  // 运行时注入
        storage.save_user(self);
    }
}
```
