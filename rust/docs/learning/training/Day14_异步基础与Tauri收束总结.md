## 今天要学什么

### 1. 为什么需要异步

#### 核心直觉
有些任务会“等”，比如：
- 网络请求
- 文件读写
- 数据库访问
- 外部服务连接

如果程序在等待这些任务时完全卡住，就会浪费时间和资源。

异步的目标就是：

> 在等待某些任务完成时，不要把整个程序都阻塞住。

#### 为什么这很重要
你未来做 Tauri 项目时，很多事情都不是瞬间完成的：
- 读取本地配置
- 请求远程接口
- 启动本地服务
- 连接 MCP server
- 查询数据库

这些都很适合异步处理。

---

### 2. `async` 和 `await` 是什么

#### 先建立最简单理解
- `async fn`：定义一个异步函数
- `.await`：等待一个异步任务完成

#### 示例（概念级）

```rust
async fn fetch_data() -> String {
    String::from("data loaded")
}

async fn run() {
    let data = fetch_data().await;
    println!("{}", data);
}
```

#### 你要理解的重点
- 异步函数不是普通函数
- 它表示“这个任务可能要等一会”
- `.await` 表示“在这里等它完成”

---

### 3. 你现在不用急着啃异步底层

Rust 异步生态后面会涉及：
- runtime（如 `tokio`）
- future
- task
- 并发调度

但对你现在来说，先建立这层认知就够了：
- 哪些场景适合异步
- `async fn` 和 `.await` 是常见写法
- 异步在 Tauri、网络请求、本地服务管理中非常常见

---

### 4. 为什么 Rust 基础和 Tauri 强相关

这 14 天你学的内容，并不是分散的小知识点。它们几乎正好构成你以后做 Tauri 后端的基本积木。

#### 对应关系
- 变量 / 基本类型：命令参数、返回数据
- 函数：command、service、工具函数
- struct：配置、状态、模型
- enum / match：状态机、结果分支、事件类型
- ownership / borrowing：参数传递、状态管理、性能优化
- Option / Result / `?`：错误处理、查找结果、配置加载
- Vec / HashMap：列表数据、映射表、缓存
- mod / pub：项目结构组织
- trait / 泛型：抽象能力与复用
- derive：调试、克隆、序列化
- async / await：文件、网络、服务连接

你现在可以把 Rust 视为：

> 一个适合把本地能力、性能、状态、安全边界“收紧”的后端语言。

## 和 Java / TS 的对比理解

### 和 Java 比
- Java 也有异步和并发机制，但 Rust 异步的工程心智不同
- Rust 更强调类型安全、显式错误和资源控制

### 和 TypeScript 比
- TS/JS 里的 async/await 你可能更熟
- Rust 的异步写法表面相似，但底层模型和约束更强
- 你以后最大的迁移挑战，不是语法，而是所有权 + 异步结合的思维
