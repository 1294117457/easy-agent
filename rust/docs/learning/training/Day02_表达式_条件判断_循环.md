## 今天要学什么

### 1. 表达式（expression）与语句（statement）

#### 是什么
- **语句**：执行一件事，但本身不返回值
- **表达式**：会计算出一个值

Rust 和很多语言不太一样，它非常重视“表达式”。

#### 你要理解的重点
- `let x = 1;` 是语句
- `1 + 2` 是表达式
- 一个代码块 `{ ... }` 也可以是表达式
- 代码块最后一行如果没有分号，它的值就会作为结果返回

#### 示例

```rust
fn main() {
    let x = 5;

    let y = {
        let z = x + 1;
        z * 2
    };

    println!("x = {}, y = {}", x, y);
}
```

这里的代码块：

```rust
{
    let z = x + 1;
    z * 2
}
```

最后一行没有分号，所以整个代码块的值就是 `z * 2`。

#### 你现在只要记住
- 不是所有代码都只是“执行”
- Rust 中很多结构都可以“返回值”
- 最后一行有没有分号，意义很大

### 2. `if / else`

#### 是什么
Rust 使用 `if / else` 做条件判断。

#### 你要理解的重点
- 条件必须是 `bool`
- `if` 不只可以控制流程，也可以作为表达式返回值
- 这会让代码更紧凑、更清晰

#### 示例 1：普通判断

```rust
fn main() {
    let age = 20;

    if age >= 18 {
        println!("成年");
    } else {
        println!("未成年");
    }
}
```

#### 示例 2：`if` 作为表达式

```rust
fn main() {
    let score = 85;

    let level = if score >= 60 {
        "通过"
    } else {
        "未通过"
    };

    println!("{}", level);
}
```

#### 你现在只要记住
- Rust 的 `if` 条件不能像 JS 那样随便写数字或字符串
- 它要求条件必须明确是 `true` 或 `false`
- `if` 可以直接赋值给变量

### 3. `loop`

#### 是什么
`loop` 是 Rust 中最基础的无限循环。

#### 你要理解的重点
- `loop` 会一直执行，直到你手动 `break`
- 它适合“必须手动退出”的场景
- `break` 甚至还能带返回值

#### 示例

```rust
fn main() {
    let mut count = 0;

    let result = loop {
        count += 1;

        if count == 3 {
            break count * 10;
        }
    };

    println!("result = {}", result);
}
```

#### 你现在只要记住
- `loop` 最灵活
- 但日常遍历数据时，不一定是首选

---

### 4. `while`

#### 是什么
`while` 表示“当条件成立时一直循环”。

#### 你要理解的重点
- 适合按条件反复执行
- 和其他语言用法接近，容易理解

#### 示例

```rust
fn main() {
    let mut n = 3;

    while n > 0 {
        println!("{}", n);
        n -= 1;
    }

    println!("结束");
}
```

---

### 5. `for`

#### 是什么
`for` 是 Rust 中最常用的遍历循环方式。

#### 你要理解的重点
- 常用于遍历数组、集合、范围
- 比手动控制索引更自然、更安全

#### 示例 1：遍历范围

```rust
fn main() {
    for i in 1..4 {
        println!("{}", i);
    }
}
```

这里的 `1..4` 表示 `1, 2, 3`，不包含 `4`。

#### 示例 2：遍历数组

```rust
fn main() {
    let nums = [10, 20, 30];

    for num in nums {
        println!("{}", num);
    }
}
```

#### 你现在只要记住
- 日常遍历优先考虑 `for`
- 它通常比 `while` 更安全也更清楚

## 今天要特别注意的概念

### 1. 最后一行没有分号 = 返回值
这在 Rust 中非常重要。

例如：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

这里 `a + b` 没有分号，所以它就是函数返回值。

如果写成：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b;
}
```

这就不对了，因为加了分号以后，它变成语句，不再返回值。

### 2. `if` 条件必须是布尔值
Rust 不像 JS，不允许你把 `1`、`0`、空字符串直接当布尔条件。

这会让代码更严谨，也更不容易产生隐式错误。

### 3. 日常遍历先想 `for`
你后面写集合、遍历配置、遍历 server 列表时，`for` 会非常常见。

## 和 Java / TS 的对比理解

### 和 Java 比
- Java 中 `if` 就是流程控制；Rust 中它还可以是表达式
- Rust 的代码块返回值更灵活
- `for` 循环写法更偏迭代风格

### 和 TypeScript 比
- TS 里很多值都能“隐式转布尔”；Rust 不允许
- Rust 更强调显式逻辑
- Rust 的表达式风格更强

## 今日小任务：做一个“登录状态提示器”

请你自己写一个小程序，要求：
- 定义一个布尔值 `is_login`
- 定义一个整数 `message_count`
- 用 `if` 生成登录提示语
- 用 `for` 打印 3 次欢迎信息
- 用 `while` 模拟消息数量递减

参考思路：

```rust
fn main() {
    let is_login = true;
    let mut message_count = 3;

    let status = if is_login {
        "用户已登录"
    } else {
        "用户未登录"
    };

    println!("{}", status);

    for i in 1..4 {
        println!("欢迎第 {} 次", i);
    }

    while message_count > 0 {
        println!("剩余消息：{}", message_count);
        message_count -= 1;
    }
}
```
