## 今天要学什么

### 1. 元组（tuple）

#### 是什么
元组是一种可以把**多个不同类型的值**放在一起的数据结构。

#### 你要理解的重点
- 元组中的元素类型可以不同
- 元组长度固定
- 常用于函数返回多个值

#### 示例

```rust
fn get_user_info() -> (&'static str, i32, bool) {
    ("Alice", 20, true)
}

fn main() {
    let user = get_user_info();
    println!("name = {}, age = {}, active = {}", user.0, user.1, user.2);
}
```

#### 解构示例

```rust
fn main() {
    let (name, age, active) = ("Bob", 22, false);
    println!("{} {} {}", name, age, active);
}
```

#### 你现在只要记住
- 元组适合把几个相关值打包返回
- 访问方式可以是 `.0`、`.1`
- 也可以直接解构

---

### 2. 数组（array）

#### 是什么
数组是**固定长度、同一类型**的数据集合。

#### 你要理解的重点
- 数组中元素类型必须一样
- 长度固定
- 适合存放数量已知且不变的数据

#### 示例

```rust
fn main() {
    let scores = [80, 90, 100];
    println!("first = {}", scores[0]);
    println!("len = {}", scores.len());
}
```

#### 你现在只要记住
- 数组很像一排固定格子
- 里面每个元素类型必须统一
- 适合小而固定的数据

---

### 3. 切片（slice）

#### 是什么
切片表示“对一段连续数据的引用”。

常见的切片有：
- 字符串切片：`&str`
- 数组切片：`&[T]`

#### 你要理解的重点
- 切片不是复制一份新数据
- 它只是“借来看看其中一部分”
- 这是后面理解借用和所有权的重要铺垫

#### 字符串切片示例

```rust
fn main() {
    let text = "hello rust";
    let part = &text[0..5];
    println!("{}", part);
}
```

#### 数组切片示例

```rust
fn main() {
    let nums = [10, 20, 30, 40, 50];
    let part = &nums[1..4];

    println!("{:?}", part);
}
```

#### 你现在只要记住
- 切片的本质是“引用一部分”
- 它不会复制全部数据
- 这对性能和安全都很重要

## 今天要特别注意的概念

### 1. 元组和数组不是一回事
- 元组：可以混合不同类型
- 数组：必须同一类型

### 2. 数组长度固定
这和你后面会学到的 `Vec<T>` 不一样。`Vec<T>` 是可变长集合，后面会学。

### 3. 切片不是复制
这点很重要。你现在先建立直觉：

> 切片更像“借看一部分”，不是“重新拷贝一份”。

这和 Rust 后面的借用机制是连着的。

---

## 和 Java / TS 的对比理解

### 和 Java 比
- Java 更常见的是数组、对象
- Rust 的元组更常用于快速返回多个值
- Rust 切片的“借用”味道更强

### 和 TypeScript 比
- TS 里数组更灵活，Rust 数组更严格
- TS 里字符串切片更像普通操作，Rust 里切片会逐步连接到内存和借用语义
