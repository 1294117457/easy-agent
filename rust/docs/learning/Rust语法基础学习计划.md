# Rust 语法基础学习计划（配套《Rust语法基础速览》）

本文是 `Rust语法基础速览.md` 的配套学习计划，目标是帮助你**深学习这些语法基础**，并结合你后续想做的 **Tauri 重构项目** 来合理安排每天的学习量。

这个计划的设计原则是：
- **从简到深**，先建立整体感，再进入 Rust 核心难点
- **每天学习量适中**，避免一开始过载
- **强调理解与实践结合**，不是只看概念
- **面向项目应用**，为后续 Tauri + Rust 重构做准备

---

## 计划总览

建议学习周期：**14 天**  
建议每日投入：**2 ~ 3 小时**  
适合人群：
- 有 Java / TS 基础
- 准备系统学习 Rust
- 后续想进入 Tauri / Web3 / 高性能工具开发

每天建议时间分配：
- **40% 阅读和理解概念**
- **40% 动手写小例子**
- **20% 复盘和整理笔记**

如果你当天状态较好，可以适当增加练习；如果当天比较忙，也至少保证“看完 + 写 2~3 个小例子”。

---

## 学习前说明

你要学习的不是“背语法”，而是逐步建立这三个能力：

1. **能看懂 Rust 代码**
2. **能自己写基础模块**
3. **能为后续项目重构打基础**

所以每一天都建议遵守这个节奏：

### 每天固定学习流程
1. 先读当天对应章节
2. 用自己的话复述“这是什么、有什么用”
3. 自己写最小示例
4. 总结今天最容易混淆的点
5. 记录 1~2 个“如果用在 Tauri 项目里会怎么用”

# 第一阶段：建立 Rust 基本语法感（Day 1 ~ Day 4）

这一阶段目标：
- 能读懂简单 Rust 代码
- 了解 Rust 和 Java / TS 的核心区别
- 建立“强类型 + 表达式 + 显式控制”的基础感受

---

## Day 1：变量、基本类型、函数、注释

### 对应章节
- 1. 变量与可变性
- 2. 基本数据类型
- 3. 函数
- 4. 注释

### 学习目标
- 明白 Rust 默认不可变是什么意思
- 认识 Rust 的常见基本类型
- 能写基础函数
- 理解类型标注在 Rust 里的重要性

### 当天学习量
建议 **2 小时左右**，不要太多。

### 重点理解
- 为什么 Rust 默认变量不可变
- `String` 和 `&str` 先有一个初步印象，不要求完全掌握
- 函数参数和返回值为什么都要写类型

### 建议练习
- 定义几个变量并尝试修改
- 写 3 个简单函数：加法、判断偶数、返回欢迎语
- 写一段带注释的小程序

### 学习结果要求
完成后你应该能：
- 看懂简单变量定义
- 看懂基础函数签名
- 写出最简单的 Rust 程序

---

## Day 2：表达式、条件判断、循环

### 对应章节
- 5. 表达式与语句
- 6. 条件判断
- 7. 循环

### 学习目标
- 理解 Rust 中“代码块也能返回值”
- 学会 `if / else`
- 学会 `loop / while / for`

### 当天学习量
建议 **2 ~ 2.5 小时**。

### 重点理解
- Rust 中很多地方不是“执行完就没了”，而是能产生值
- `if` 不只是判断，还可以返回值
- `for` 是最常用循环方式

### 建议练习
- 用 `if` 返回不同数字或字符串
- 用 `for` 遍历数组
- 用 `while` 实现倒计时
- 用 `loop` 手动 `break`

### 学习结果要求
完成后你应该能：
- 看懂简单流程控制代码
- 理解 Rust 风格的“表达式式编程”

---

## Day 3：元组、数组、切片

### 对应章节
- 10. 切片
- 11. 元组与数组

### 学习目标
- 了解固定结构数据的表达方式
- 理解切片是“借用一部分数据”的思想
- 为后面学习借用做铺垫

### 当天学习量
建议 **2 小时左右**。

### 重点理解
- 元组适合返回多个值
- 数组长度固定
- 切片不是复制，而是引用一部分数据

### 建议练习
- 写一个函数返回元组
- 定义数组并遍历
- 获取字符串的一部分切片
- 获取数组切片

### 学习结果要求
完成后你应该能：
- 区分元组、数组、切片
- 知道切片和复制的不同

---

## Day 4：结构体与基础建模

### 对应章节
- 12. 结构体（struct）
- 18. 方法与 `impl`

### 学习目标
- 学会用 struct 表达业务对象
- 知道如何给结构体定义方法
- 建立“数据 + 行为”组织意识

### 当天学习量
建议 **2.5 小时**。

### 重点理解
- struct 不是简单字段堆积，而是业务模型
- `impl` 是给类型定义行为的地方
- 这部分和你未来做 Tauri 项目关系很大

### 建议练习
- 定义 `User`、`ServerConfig`、`Plugin` 结构体
- 给结构体加 `new`、`display`、`update` 之类简单方法
- 尝试模拟你项目里的一个对象

### 学习结果要求
完成后你应该能：
- 自己定义 struct
- 自己给 struct 写方法
- 初步感受到 Rust 做业务建模的方式

# 第二阶段：进入 Rust 核心能力（Day 5 ~ Day 9）

这一阶段是 Rust 学习的重点。  
目标是开始真正理解 Rust 的“安全与性能”是怎么来的。

---

## Day 5：所有权（Ownership）

### 对应章节
- 8. 所有权（Ownership）

### 学习目标
- 理解“每个值只有一个所有者”
- 理解变量赋值、传参时可能发生所有权转移
- 知道为什么 Rust 不需要垃圾回收也能安全

### 当天学习量
建议 **3 小时**。这是第一天明显变难。

### 重点理解
- 什么叫 move
- 什么叫作用域结束自动释放
- 为什么有些类型赋值后还能继续用，有些不行

### 建议练习
- 写字符串赋值示例，观察 move 行为
- 写函数接收 `String`，看调用后原变量还能不能用
- 对比整数赋值与字符串赋值

### 学习结果要求
完成后你应该能：
- 理解最基础的 ownership 规则
- 看懂“为什么这段代码被编译器拒绝”

---

## Day 6：借用与引用

### 对应章节
- 9. 借用（Borrowing）与引用
- 10. 切片（复习）

### 学习目标
- 理解 `&T` 和 `&mut T`
- 知道什么时候借用比转移所有权更合适
- 了解可变借用和不可变借用的限制

### 当天学习量
建议 **3 小时**。

### 重点理解
- 借用是“临时使用”，不是“拿走所有权”
- 同一时刻可变借用和不可变借用的规则
- 这是你以后写函数、写服务层、写状态管理的基础

### 建议练习
- 写接受 `&String` 的函数
- 写接受 `&mut String` 并修改内容的函数
- 同时尝试多个借用，观察哪些能编译、哪些不行

### 学习结果要求
完成后你应该能：
- 区分所有权传递和借用
- 理解编译器为什么限制并发修改

---

## Day 7：枚举与 match

### 对应章节
- 13. 枚举（enum）
- 14. 模式匹配（match）

### 学习目标
- 理解 enum 不只是“常量枚举”，而是状态建模工具
- 掌握 `match` 的基本使用
- 开始接触 Rust 很有代表性的写法

### 当天学习量
建议 **2.5 ~ 3 小时**。

### 重点理解
- enum 可以带数据
- match 要求分支尽量完整
- Rust 在状态建模上比很多语言更强

### 建议练习
- 定义 `ConnectionStatus` 枚举
- 定义 `Message` 枚举
- 使用 `match` 处理不同状态
- 模拟连接成功、失败、加载中的分支

### 学习结果要求
完成后你应该能：
- 用 enum 表达业务状态
- 用 match 清晰地写分支逻辑

---

## Day 8：Option 与 Result

### 对应章节
- 15. Option
- 16. Result
- 17. `?` 操作符

### 学习目标
- 理解 Rust 如何处理“值不存在”和“操作失败”
- 理解 `Option` 和 `Result` 的典型用途
- 学会最基础的 `?` 用法

### 当天学习量
建议 **3 小时**。

### 重点理解
- `Option` 是处理“可能为空”
- `Result` 是处理“可能失败”
- `?` 是简化错误传递的重要语法

### 建议练习
- 写一个查找函数返回 `Option`
- 写一个解析函数返回 `Result`
- 用 `?` 串联两个可能失败的步骤
- 模拟读取配置、解析 JSON 的结果返回

### 学习结果要求
完成后你应该能：
- 看懂大多数基础错误处理代码
- 开始具备写真实项目逻辑的基础

---

## Day 9：生命周期初识

### 对应章节
- 21. 生命周期（Lifetime）

### 学习目标
- 不求深入掌握，只求先建立正确认知
- 理解生命周期是为了解决“引用有效期”问题
- 知道不是所有地方都需要自己写生命周期标注

### 当天学习量
建议 **2 小时**。

### 重点理解
- 生命周期不是“运行时间”，而是引用关系的静态约束
- 前期只要先理解“为什么会需要它”
- 不建议在这一天追求彻底精通

### 建议练习
- 看几个简单生命周期示例
- 理解“返回引用时为什么需要更严格规则”
- 用自己的话解释生命周期存在的意义

### 学习结果要求
完成后你应该能：
- 不再把生命周期看成神秘概念
- 知道它和借用安全有关

# 第三阶段：进入工程化能力（Day 10 ~ Day 14）

这一阶段会把语法基础逐步连接到真实项目开发。

---

## Day 10：集合类型

### 对应章节
- 22. 集合类型

### 学习目标
- 学会最常用的 `Vec<T>` 和 `HashMap<K, V>`
- 了解集合在业务开发中的常见用途

### 当天学习量
建议 **2 小时**。

### 重点理解
- `Vec` 是最常用的数据容器
- `HashMap` 适合做映射关系
- Rust 集合经常和借用、迭代一起出现

### 建议练习
- 用 `Vec` 存储多个 server
- 用 `HashMap` 存储配置键值对
- 遍历集合并做简单筛选

### 学习结果要求
完成后你应该能：
- 用集合存储业务数据
- 看懂 Rust 常见容器代码

---

## Day 11：模块、可见性、项目组织

### 对应章节
- 23. 模块（mod）与可见性（pub）
- 24. 包（crate）与项目组织
- 29. Cargo

### 学习目标
- 理解 Rust 项目如何拆文件、拆模块
- 理解 `mod`、`pub`、`crate` 的基本作用
- 了解 Cargo 是如何管理工程的

### 当天学习量
建议 **2.5 小时**。

### 重点理解
- 小练习代码和真实项目代码的组织方式不同
- Rust 工程结构清晰很重要
- 这是未来重构 Tauri 项目的基础

### 建议练习
- 手动拆一个小项目为多个模块
- 练习 `pub` 的可见性控制
- 新建一个 Cargo 项目并增加一个依赖

### 学习结果要求
完成后你应该能：
- 看懂简单 Rust 项目目录结构
- 自己组织基本模块

---

## Day 12：Trait、泛型、derive

### 对应章节
- 19. Trait
- 20. 泛型（Generics）
- 28. 常用派生能力（derive）

### 学习目标
- 理解 trait 是“行为约定”
- 知道泛型的作用
- 了解 derive 为何这么常见

### 当天学习量
建议 **2.5 ~ 3 小时**。

### 重点理解
- trait 类似接口，但也有 Rust 自己的风格
- 泛型是为了通用化代码
- derive 在真实项目中非常高频

### 建议练习
- 定义一个简单 trait，如 `DisplayInfo`
- 为两个 struct 实现同一个 trait
- 写一个泛型函数
- 练习 `Debug`、`Clone`、`Serialize`、`Deserialize`

### 学习结果要求
完成后你应该能：
- 看懂大部分基础抽象代码
- 明白真实项目里 derive 的高频价值

---

## Day 13：宏、错误处理设计

### 对应章节
- 25. 宏（Macro）
- 27. 错误处理设计

### 学习目标
- 知道宏是什么，不要求深入手写复杂宏
- 理解 Rust 项目中错误处理应该如何设计

### 当天学习量
建议 **2 小时**。

### 重点理解
- 宏是“生成代码的工具”，先会用常见宏即可
- 不可恢复错误和可恢复错误要区分
- 项目中不要滥用 `panic!`

### 建议练习
- 识别 `println!`、`vec!`、`format!` 的使用方式
- 模拟配置读取失败、解析失败的错误设计
- 写几个返回 `Result` 的函数

### 学习结果要求
完成后你应该能：
- 理解宏在 Rust 中为什么常见
- 理解项目里为什么更常返回错误而不是直接崩溃

---

## Day 14：异步基础 + 面向 Tauri 的总结

### 对应章节
- 26. 异步（async/await）
- 30. 为什么这些基础对 Tauri/Web3 有用

### 学习目标
- 对 Rust 异步编程有初步概念
- 把前 13 天的基础知识连接到未来项目重构
- 完成第一轮学习闭环

### 当天学习量
建议 **2.5 小时**。

### 重点理解
- `async/await` 主要解决 IO 密集场景
- Tauri 项目常见场景：文件读写、网络请求、状态管理、命令调用
- 你不是“学完 Rust”，而是“学到能开始做项目”

### 建议练习
- 写一个最简单的 async 函数
- 看一个异步请求示例
- 总结哪些知识点最适合先用于 Tauri
- 写出“我下一步准备用 Rust 重构项目的哪一块”

### 学习结果要求
完成后你应该能：
- 对 Rust 异步有初步认识
- 能把基础语法和实际项目连接起来

# 每周复盘建议

除了每天学习，建议每 7 天做一次小复盘。

## 第 1 周复盘（Day 7 后）
你要问自己：
- 我是否理解 Rust 和 TS / Java 在语法风格上的明显差异？
- 我是否真正理解了 ownership 和 borrowing？
- 我能否写出简单的 struct / enum / match 代码？

## 第 2 周复盘（Day 14 后）
你要问自己：
- 我能否读懂一个基础 Rust 小项目？
- 我是否理解 `Option` / `Result` 的常见用法？
- 我是否能开始尝试 Tauri 中的 Rust command 开发？

# 学习过程中的优先级建议

如果你后面是为了做 Tauri 重构，这些内容优先级最高：

## 第一优先级
- 变量、函数、基本类型
- 所有权、借用、引用
- struct、enum、match
- Option、Result、`?`

## 第二优先级
- Vec、HashMap
- impl、trait
- 模块、Cargo
- derive、serde

## 第三优先级
- 生命周期深入
- 宏深入
- 更复杂的泛型设计
- 异步进阶

也就是说：
**先学会做项目，再逐步吃透更深的 Rust。**

# 学完这份计划后，你下一步该做什么

完成这 14 天计划后，最适合你的下一步不是继续纯看语法，而是进入：

1. **用 Rust 写几个小练习项目**
   - 配置解析器
   - 本地文件读写
   - server 状态模型
   - 简单 SQLite CRUD

2. **开始最小 Tauri 项目**
   - Vue 前端 + Rust command
   - 一个按钮调用一个 Rust 函数
   - 做配置读取或简单状态返回

3. **再开始迁移现有项目的一小块模块**
   - 例如 MCP 配置解析
   - 或本地持久化的一部分
   - 或 server 状态建模
