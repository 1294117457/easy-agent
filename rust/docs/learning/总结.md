##### 2表达式/if

```
表达式/语句
    fn main() {
        let x = 5 + 3;          // `5 + 3` 是表达式，返回 8
        let y = {               // 代码块也是表达式
            let a = 2;
            a * 3               // 最后一行没有分号，返回 6
        };                      // 整个块的值赋给 y
    }

有分号是表达式，无分号是语句
整个方法{}就是表达式，末尾无表达式则为隐式返回()
```

```
if
    fn main() {
        let x = 10;
        let y = 20;

        let result = if x > y {
            if x > 100 { "x很大" } else { "x中等" }
        } else {
            if y > 100 { "y很大" } else { "y中等" }
        };

        println!("{}", result);  // 输出: y中等
    }
```

##### 3loop/while/for

需要控制结束并返回的用loop 

遍历用for 

循环用while

```
loop
	fn main() {
        let mut count = 0;
        let result = loop {
            count += 1;
            if count == 3 {
                break count * 10;
            }
        };
        println!("result = {}", result);
    }
loop的返回值为break携带的
```

```
while
	fn main() {
        let mut n = 3;

        while n > 0 {
            println!("{}", n);
            n -= 1;
        }

        println!("结束");
    }	
```

```
for 
	fn main() {
        for i in 1..4 {
            println!("{}", i);
        }
    }
```
