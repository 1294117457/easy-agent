##### 6onwership

```
1. Rust 中每个值都有一个所有者
2. 同一时刻只能有一个所有者
3. 所有者离开作用域后，值会被自动释放

作用域、所有者/move，copy
```

```
总结
	所有权针对一个值或者一个对象的，哪个变量拥有这个值或变量的所有权对吗
	类似java中的引用和对象的关系，
		但是这里所有权是一对一的，一个对象只会被一个变量所拥有，
		java中的对象可以被多次引用对吗
	move只是所有权转移的概念，let owner=build_name();
```

##### 7borrowing/reference

```
为了避免频繁切换所有权，借用
	&T：不可变引用，只读借用
    &mut T：可变引用，可修改借用
    借用不等于复制、不转移所有权
关键
	可以同时多个不可变引用，只能由一个可变引用
	可变引用和不可变引用不能同时存在
```

```
实际还是说一个对象的引用，但是rust中的有明显的绑定关系，
    对象同时只能有一个ownership，其他都是临时的引用
    而比如java中，一个对象可以有多个引用，这多个引用都是长期指向这个对象
    
然后rust中的引用还区分可变和不可变，
	可变只能一个，不可变多个
```

```
fn parse_number(text: &str) -> Result<i32, String> {
    match text.parse::<i32>() {
        Ok(num) => Ok(num),
        Err(_) => Err(String::from("解析失败")),
    }
}

fn double_number(text: &str) -> Result<i32, String> {
    let num = parse_number(text)?;
    Ok(num * 2)
}

等价于
fn double_number(text: &str) -> Result<i32, String> {
    let num = match parse_number(text) {
        Ok(v)  => v,       // 成功：取出值，继续执行
        Err(e) => return Err(e),  // 失败：立刻返回 Err
    };
    Ok(num * 2)
}

首先parse_number就是一个Result
然后?表示，
	如果是Ok，则返回Ok对应的值，比如num=25
	如果parse_number是Err("错误")，就是直接传出Err("错误")给doublie_number这个Result
```

```
fn longest<'a>(a: &'a str, b: &'a str) -> &'a str

fn main() {
    let result;
    {
        let s1 = String::from("long");
        let s2 = String::from("short");
        result = longest(&s1, &s2);  // 编译器检查：s1 和 s2 必须活得一样久
```




| 操作   | 数组 `[T; n]`   | Vec                     | HashMap             |
| :----- | :-------------- | :---------------------- | :------------------ |
| Create | `[1,2,3]`       | `vec![1,2,3]`           | `HashMap::new()`    |
| 读取   | `arr[i]`        | `v[i]` / `v.get(i)`     | `map.get(key)`      |
| 插入   | `arr[i]=x`      | `v.push(x)`             | `map.insert(k,v)`   |
| 更新   | `arr[i]=x`      | `v[i]=x`                | `map.insert(k,v)`   |
| 删除   | 需转Vec         | `v.remove(i)` / `pop()` | `map.remove(key)`   |
| 遍历   | `for x in &arr` | `for x in &v`           | `for (k,v) in &map` |
