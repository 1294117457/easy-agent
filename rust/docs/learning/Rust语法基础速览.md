# Rust 语法基础速览

本文按“从简至深”的顺序，简要介绍 Rust 的常见语法基础。目标不是展开细讲，而是让你先知道：**它是什么、有什么用**。

---

## 1. 变量与可变性

### 是什么
Rust 使用 `let` 定义变量，默认是**不可变**的；如果想修改，需要显式加 `mut`。

### 有什么用
它能帮助你在代码一开始就区分“这个值是否允许被修改”，让程序更安全，也更容易排查问题。

---

## 2. 基本数据类型

### 是什么
Rust 提供常见基础类型，例如：
- 整数：`i32`、`u64`
- 浮点数：`f32`、`f64`
- 布尔：`bool`
- 字符：`char`
- 字符串：`String`、`&str`

### 有什么用
它们是构建程序最基础的数据单位。Rust 的类型系统比较严格，可以在编译阶段提前发现很多错误。

---

## 3. 函数

### 是什么
函数使用 `fn` 定义，参数和返回值都要明确写类型。

### 有什么用
函数是组织逻辑的基本方式。Rust 强制你把输入输出写清楚，有利于代码可读性和维护性。

---

## 4. 注释

### 是什么
Rust 支持单行注释、多行注释，也支持文档注释。

### 有什么用
注释用于说明代码意图。文档注释还可以生成 API 文档，适合做库或模块说明。

---

## 5. 表达式与语句

### 是什么
Rust 中很多代码块本身就是**表达式**，可以直接产生值。

### 有什么用
这让 Rust 在写条件分支、匹配和函数返回时更简洁，也更适合函数式风格的表达。

---

## 6. 条件判断

### 是什么
Rust 使用 `if / else` 进行条件判断，而且 `if` 也是表达式。

### 有什么用
它既能控制流程，也能直接返回值，适合写清晰的分支逻辑。

---

## 7. 循环

### 是什么
Rust 常见循环有：
- `loop`
- `while`
- `for`

### 有什么用
用于重复执行逻辑。`for` 常用于遍历集合，`while` 常用于条件循环，`loop` 更适合手动控制退出。

---

## 8. 所有权（Ownership）

### 是什么
所有权是 Rust 最核心的概念。每个值在同一时刻只能有一个“所有者”，超出作用域后会自动释放。

### 有什么用
它让 Rust 不依赖垃圾回收，也能安全地管理内存，是 Rust 同时兼顾性能和安全的关键机制。

---

## 9. 借用（Borrowing）与引用

### 是什么
Rust 允许通过引用 `&T` 或可变引用 `&mut T` 来访问数据，而不是直接转移所有权。

### 有什么用
借用能避免不必要的拷贝，也能让多个函数共享访问数据。它是写高性能 Rust 代码的基础。

---

## 10. 切片（Slice）

### 是什么
切片是对一段连续数据的引用，比如字符串切片 `&str`，数组切片 `&[T]`。

### 有什么用
它可以在不复制数据的情况下，只查看其中一部分内容，非常适合处理文本和集合。

---

## 11. 元组与数组

### 是什么
- 元组：可以把不同类型的数据放在一起
- 数组：固定长度、同一类型的数据集合

### 有什么用
元组适合返回多个值；数组适合表示固定大小的数据。

---

## 12. 结构体（struct）

### 是什么
结构体用于把多个相关字段组织成一个新的类型。

### 有什么用
它适合建模现实中的对象，比如用户、配置、订单、MCP Server 等，是业务建模的重要基础。

---

## 13. 枚举（enum）

### 是什么
枚举表示“一个值可能是多种状态中的一种”，并且每种状态还可以携带不同数据。

### 有什么用
这是 Rust 非常强大的建模工具。适合描述状态机、结果类型、消息类型等，很多场景比传统面向对象更自然。

---

## 14. 模式匹配（match）

### 是什么
`match` 是 Rust 的分支匹配语法，可以对枚举、数字、字符串模式等进行匹配。

### 有什么用
它能让你把复杂分支写得清楚完整，尤其适合处理 `enum`、`Option` 和 `Result`。

---

## 15. Option

### 是什么
`Option<T>` 表示“一个值可能存在，也可能不存在”，常见两种状态：
- `Some(T)`
- `None`

### 有什么用
它替代很多语言里的 `null`，减少空指针问题，让“值可能为空”这件事变得显式可控。

---

## 16. Result

### 是什么
`Result<T, E>` 表示“操作可能成功，也可能失败”，常见两种状态：
- `Ok(T)`
- `Err(E)`

### 有什么用
它是 Rust 错误处理的核心方式。相比直接抛异常，它更显式、更可控，更适合构建可靠系统。

---

## 17. `?` 操作符

### 是什么
`?` 是 Rust 中简化错误传播的语法。

### 有什么用
当函数返回 `Result` 或 `Option` 时，`?` 可以减少大量样板代码，让错误处理更简洁。

---

## 18. 方法与 `impl`

### 是什么
Rust 使用 `impl` 为结构体或枚举定义方法。

### 有什么用
它让数据和行为能够组织在一起，便于封装业务逻辑。

---

## 19. Trait

### 是什么
`trait` 类似于“行为约定”或“接口”，用于定义一组共享能力。

### 有什么用
它让不同类型可以拥有统一行为，是 Rust 抽象设计和泛型编程的基础。

---

## 20. 泛型（Generics）

### 是什么
泛型允许你写出适用于多种类型的通用代码。

### 有什么用
它能提升代码复用性，同时保持类型安全。标准库中的很多容器和工具都依赖泛型。

---

## 21. 生命周期（Lifetime）

### 是什么
生命周期用于描述引用在多长时间内有效。

### 有什么用
它帮助编译器保证引用不会悬空。虽然一开始看起来难，但本质上是在解决“谁活得更久、引用是否安全”的问题。

---

## 22. 集合类型

### 是什么
Rust 标准库中常见集合包括：
- `Vec<T>`：动态数组
- `HashMap<K, V>`：键值对映射
- `HashSet<T>`：集合

### 有什么用
它们用于存储和管理多条数据，是业务开发中最常用的数据结构。

---

## 23. 模块（mod）与可见性（pub）

### 是什么
Rust 用模块来组织代码，用 `pub` 控制哪些内容可以被外部访问。

### 有什么用
它能帮助你建立清晰的项目结构，避免代码混乱，也是大型工程的基础。

---

## 24. 包（crate）与项目组织

### 是什么
Rust 项目通常由一个或多个 `crate` 组成，使用 Cargo 进行管理。

### 有什么用
它是 Rust 工程化的核心。你可以把应用、库、工具模块清晰拆分，便于维护和扩展。

---

## 25. 宏（Macro）

### 是什么
宏是一种生成代码的机制，例如 `println!`、`vec!` 都是宏。

### 有什么用
宏可以减少重复代码，提高表达力。Rust 中很多常见语法糖背后都依赖宏。

---

## 26. 异步（async/await）

### 是什么
Rust 支持异步编程，通常配合 `async` / `await` 和异步运行时使用。

### 有什么用
它适合处理网络请求、文件 IO、并发任务等场景，能在高并发下获得更好的资源利用率。

---

## 27. 错误处理设计

### 是什么
Rust 鼓励区分“可恢复错误”和“不可恢复错误”，分别使用 `Result` 和 `panic!` 等方式处理。

### 有什么用
它让程序的失败路径更明确，特别适合写稳定的后端、系统工具和桌面应用。

---

## 28. 常用派生能力（derive）

### 是什么
Rust 可以用 `derive` 自动为类型生成一些常见能力，比如：
- `Debug`
- `Clone`
- `Serialize`
- `Deserialize`

### 有什么用
它可以大大减少模板代码，尤其在日志、复制、JSON 序列化等场景非常实用。

---

## 29. Cargo

### 是什么
Cargo 是 Rust 的构建与包管理工具。

### 有什么用
它负责：
- 创建项目
- 管理依赖
- 编译代码
- 运行测试
- 构建发布

几乎所有 Rust 项目都离不开它。

---

## 30. 为什么这些基础对 Tauri/Web3 有用

### 对 Tauri 有什么用
- `struct / enum`：适合做桌面应用状态建模
- `Result / ?`：适合做命令调用和错误返回
- `serde`：适合前后端 JSON 数据交互
- `async/await`：适合处理网络请求、文件操作、服务连接
- 模块与 trait：适合拆分业务层、存储层、接口层

### 对 Web3 有什么用
- Rust 在高性能系统、链上/链下工具中很常见
- 强类型和内存安全对签名、状态管理、工具链开发很有价值
- 异步、错误处理、序列化能力很适合 RPC、索引器、客户端、钱包类工具开发

---

## 建议你怎么学

如果你现在是为了后续用 Tauri 重构项目，建议学习顺序这样排：

1. 变量、函数、基本类型
2. 所有权、借用、引用
3. `struct`、`enum`、`match`
4. `Option`、`Result`、`?`
5. `Vec`、`HashMap`
6. 模块、`impl`、`trait`
7. `serde`、Cargo
8. `async/await`
9. 再进入 Tauri 项目实践

---

## 一句话总结

Rust 的语法基础并不只是“怎么写代码”，更重要的是它通过**所有权、类型系统、错误处理和模块化设计**，帮助你写出更安全、更稳定、更高性能的程序。

如果你后面要走 **Tauri + Rust + Web3** 这条路线，这些基础都是非常值得尽早掌握的。
