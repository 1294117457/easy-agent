```
总得来说三层
llm
	聚焦于对话功能
	apikey在这层和llm强关联
agent层
	功能层
	prompt、skill、mcp、tool在这层强关联
graph层
	编排agent
	memory、state、storage在
```

##### 分层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │                                                          │  │
│   │   Layer 1：LLM（底层能力）                               │  │
│   │   ─────────────────────                                 │  │
│   │                                                          │  │
│   │   · 只关心"对话"一件事                                   │  │
│   │   · 输入 String → 输出 String                           │  │
│   │   · 可替换：OpenAI / Claude / 本地模型                  │  │
│   │   · 生命周期：与 Graph/Agent 解耦                       │  │
│   │                                                          │  │
│   │   可选：Pool（LLM 连接池）← 多实例共享                  │  │
│   │                                                          │  │
│   └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│                         ▲                                       │
│                         │ 委托                                  │
│                         ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │                                                          │  │
│   │   Layer 2：Agent（运行时实体）                          │  │
│   │   ───────────────────────                                │  │
│   │                                                          │  │
│   │   · 持有 LLM（注入）                                     │  │
│   │   · 持有资源：Prompt / Skill / MCP                      │  │
│   │   · 持有局部状态                                         │  │
│   │   · chat() = 构造 prompt + 调用 LLM + 写 Memory        │  │
│   │                                                          │  │
│   │   实例化方式：                                           │  │
│   │   · Agent::new(llm, resources, config)                  │  │
│   │                                                          │  │
│   └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│                         ▲                                       │
│                         │ 编排                                  │
│                         ▼                                       │
│   ┌──────────────────────────────────────────────────────────┐  │
│   │                                                          │  │
│   │   Layer 3：Graph（拓扑编排）                             │  │
│   │   ──────────────────────                                 │  │
│   │                                                          │  │
│   │   · 管理多个 Agent 的生命周期                            │  │
│   │   · 定义 Agent 之间的 Edge（消息路由）                  │  │
│   │   · 全局共享：Memory / State / Storage                  │  │
│   │                                                          │  │
│   │   实例化方式：                                           │  │
│   │   · Graph::new(memory, state, storage)                 │  │
│   │   · graph.add_agent(Agent::new(...))                   │  │
│   │   · graph.add_edge(from, to, condition)                │  │
│   │                                                          │  │
│   └──────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

##### 资源/全局模型

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   资源模型（Agent 私有）          全局模型（Graph 共享）         │
│   ─────────────────────          ─────────────────────         │
│                                                                 │
│   Prompt    · 每个 Agent 可有不同 prompt                       │
│   Skill     · Agent A 会编程，Agent B 会搜索                   │
│   MCP       · Agent A 用文件 MCP，Agent B 用数据库 MCP        │
│                                                                 │
│                         VS                                     │
│                                                                 │
│   Memory    · 所有 Agent 共享同一个记忆库                        │
│   State     · 全局上下文，所有 Agent 都可读写                    │
│   Storage   · 统一数据库连接，统一缓存管理                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
