## 1. Core 核心层

核心抽象，定义最基础的接口和类型。

### 1.1 State (状态)

**功能：**
- 定义状态结构体 `trait State`
- 状态合并策略（合并、覆盖、追加）
- 状态快照 `Snapshot`（用于 Checkpoint/回滚）
- 状态验证器

**对应 LangGraph：** `State`

### 1.2 Node (节点)

**功能：**
- 定义节点接口 `trait Node`
- 节点输入/输出类型
- 节点超时配置
- 节点错误处理策略

**对应 LangGraph：** `Node`

### 1.3 Edge (边)

**功能：**
- 固定边 `FixedEdge`
- 条件边 `ConditionalEdge` + 条件函数 `Fn(State) -> EdgeTarget`
- 边优先级
- 边重试策略

**对应 LangGraph：** `Edge` + `addConditionalEdges`

### 1.4 Graph (图)

**功能：**
- 图的构建 `GraphBuilder`
- 添加节点 `add_node`
- 添加边 `add_edge`
- 添加条件边 `add_conditional_edge`
- START / END 边界定义
- 图验证（无孤立节点、边指向有效节点等）

**对应 LangGraph：** `Graph`

### 1.5 Engine (引擎)

**功能：**
- 图执行器 `Engine`
- 单步执行 `execute_step`
- 全图执行 `execute_graph`
- 中断点支持 `interrupt`
- 恢复执行 `resume`
- 并行节点执行（分支场景）

**对应 LangGraph：** `CompiledGraph` / `invoke`

## 2. LLM 模型层

接入各大语言模型提供商。

### 2.1 Provider (提供商抽象)

**功能：**
- 定义 `trait LLMProvider`
- 统一接口：`chat()`, `chat_stream()`
- 模型列表管理
- Token 计数

### 2.2 OpenAI

**功能：**
- GPT-4o / GPT-4o-mini / GPT-4-Turbo
- Chat Completions API
- 流式输出
- Function Calling / Tool Use
- Vision (图片理解)
- JSON Mode
- Temperature / Top-p 参数

### 2.3 Anthropic

**功能：**
- Claude 3.5 Sonnet / Claude 3 Opus / Claude 3 Haiku
- Messages API
- 流式输出
- Vision (图片理解)
- Extended Thinking (思考过程)
- Tool Use

### 2.4 Ollama

**功能：**
- 本地模型调用（Llama3 / Qwen / Phi 等）
- REST API 对接
- 流式输出
- 模型列表查询
- 嵌入向量 `embeddings`

### 2.5 Gemini (可选扩展)

**功能：**
- Google Gemini API
- 多模态支持
- Function Calling

### 2.6 Model Config (模型配置)

**功能：**
- 模型参数配置结构体
- 支持的模型列表
- 默认参数设置

## 3. Memory 记忆层

对话历史管理策略。

### 3.1 Memory Trait (记忆接口)

**功能：**
- 定义 `trait Memory`
- 添加消息 `add()`
- 获取历史 `history()`
- 清空 `clear()`
- 消息截断/裁剪

### 3.2 WindowMemory (滑动窗口)

**功能：**
- 保留最近 N 条消息
- 按 token 数限制（而非消息条数）
- 可配置窗口大小

### 3.3 SummarizeMemory (总结记忆)

**功能：**
- 定期总结历史对话
- 保留摘要，丢弃细节
- 可配置触发阈值（消息数 / token 数）

### 3.4 VectorMemory (向量记忆)

**功能：**
- 消息 embedding 存储
- 语义检索 `search(query)` → 相关消息
- 基于余弦相似度排序
- 可选 Ollama 本地 embedding 或 OpenAI embedding API

### 3.5 HybridMemory (混合记忆)

**功能：**
- 短期记忆：WindowMemory
- 长期记忆：VectorMemory
- 摘要记忆：SummarizeMemory
- 自动分层管理

### 3.6 Checkpoint (检查点)

**功能：**
- 状态快照保存
- 指定时间点回滚
- 用于长对话中的错误恢复

## 4. Tool 工具层

Agent 调用外部能力的方式。

### 4.1 Tool Trait (工具接口)

**功能：**
- 定义 `trait Tool`
- 工具名称 `name()`
- 工具描述 `description()`
- 参数 schema `parameters()`
- 执行方法 `execute()`

### 4.2 Tool Registry (工具注册表)

**功能：**
- 工具注册 `register()`
- 工具查找 `get()`
- 工具列表 `list_tools()`
- 工具描述导出（供 LLM 知道可用工具）

### 4.3 Built-in Tools (内置工具)

**功能：**
- `FileTool` - 文件读写、搜索
- `SearchTool` - 网络搜索
- `CalculatorTool` - 数学计算
- `DateTimeTool` - 日期时间
- `CodeRunnerTool` - 执行代码（Python / JS）

### 4.4 Tool Executor (工具执行器)

**功能：**
- 异步执行
- 超时控制
- 重试机制
- 执行结果格式化

### 4.5 Tool Call Result (工具调用结果)

**功能：**
- 成功结果包装
- 错误处理
- 重试标记

## 5. MCP 协议层

Model Context Protocol，连接外部工具服务。

### 5.1 MCP Client (客户端)

**功能：**
- 连接 MCP 服务器
- 协议握手
- 心跳保活
- 自动重连

### 5.2 MCP Protocol (协议定义)

**功能：**
- JSON-RPC 2.0 封装
- 请求/响应序列化
- 错误码定义
- 协议版本协商

### 5.3 MCP Transport (传输层)

**功能：**
- Stdio 传输（子进程通信）
- HTTP/SSE 传输（远程服务）
- WebSocket 传输

### 5.4 MCP Tool Bridge (工具桥接)

**功能：**
- 将 MCP 工具转换为 RustGraph `Tool`
- 动态工具发现
- 统一工具调用接口

## 6. Agent 智能体层

具体的 Agent 实现模式。

### 6.1 SingleAgent (单 Agent)

**功能：**
- 最基础的 Agent
- LLM + Memory + Tools
- 用户输入 → LLM → 决策（直接回复 / 调用工具）→ 返回

### 6.2 ReActAgent (ReAct 模式)

**功能：**
- Thought → Action → Observation 循环
- 最大步数限制
- 中断条件定义

### 6.3 PlanAgent (计划型 Agent)

**功能：**
- 先规划再执行
- 子任务分解
- 计划验证

### 6.4 MultiAgent (多 Agent)

**功能：**
- Agent 间通信
- 消息传递
- Agent 生命周期管理

### 6.5 SupervisorAgent (主管模式)

**功能：**
- 一个主管 Agent 协调多个工作 Agent
- 任务分发
- 结果汇总

### 6.6 Handoff (交接)

**功能：**
- Agent 之间交接
- 上下文传递
- 交接协议定义

## 7. Storage 存储层

持久化支持。

### 7.1 Storage Trait (存储接口)

**功能：**
- 定义 `trait Storage`
- 键值存储 `save()`, `load()`, `delete()`

### 7.2 FileStorage (文件存储)

**功能：**
- JSON 文件持久化
- 文件路径管理
- 备份机制

### 7.3 SqliteStorage (SQLite 存储)

**功能：**
- SQLite 数据库
- 结构化查询
- 索引支持

### 7.4 SessionStorage (会话存储)

**功能：**
- 基于会话 ID 的存储
- 会话过期管理
- 会话列表

### 7.5 ConfigStorage (配置存储)

**功能：**
- API Key 安全存储
- 模型配置持久化
- 用户偏好设置

## 8. Graph 图执行层

图的高级编排能力。

### 8.1 Conditional Graph (条件图)

**功能：**
- 根据 State 动态决定下一步
- 多条件分支
- 条件优先级

### 8.2 State Graph (状态图)

**功能：**
- 基于状态的图
- 状态更新触发边
- 状态转换事件

### 8.3 Branch (分支)

**功能：**
- 并行分支执行
- 分支结果合并
- 超时控制

### 8.4 Loop (循环)

**功能：**
- 循环节点定义
- 循环终止条件
- 最大迭代次数

### 8.5 Interrupt (中断)

**功能：**
- 中断点设置
- 外部触发恢复
- 状态保存

### 8.6 Stream (流式输出)

**功能：**
- LLM 流式响应
- 工具执行进度
- 自定义事件流

## 开发优先级建议

| 优先级 | 模块 | 原因 |
| :--- | :--- | :--- |
| P0 | Core (State, Node, Edge, Graph, Engine) | 其他所有模块都依赖它 |
| P0 | LLM (Provider, OpenAI) | 最基础的对话能力 |
| P0 | Memory (WindowMemory) | 对话历史必须 |
| P1 | Tool (Trait, Registry, Executor) | 扩展 Agent 能力 |
| P1 | SingleAgent / ReActAgent | 具体 Agent 实现 |
| P2 | Anthropic / Ollama | 补充模型支持 |
| P2 | Storage | 持久化支持 |
| P2 | VectorMemory | 语义搜索能力 |
| P3 | MCP | 外部协议接入 |
| P3 | MultiAgent / Supervisor | 复杂协作场景 |
| P3 | Checkpoint | 回滚恢复能力 |
